# Concise Writing Standards

## Goal
Write text that is polite, succinct, short, and direct. Cut cognitive load and token cost — both when writing and when reading later.

## Rules
1. **Every word must add meaning.** If a word adds nothing, remove it.
2. **Back conclusions with hard data.** When data isn't available, derive the conclusion only if it is explainable. State the reasoning in one short sentence.
3. **Avoid assumptions.** When one is unavoidable, state it explicitly as an assumption.
4. **Be direct.** No fluff, no filler, no hedging qualifiers (`basically`, `actually`, `currently`, `in the process of`).
5. **Stay polite but brief.** Respect the reader; brevity is a form of respect for their time.
6. **A direct yes/no question gets only "Yes." or "No."** Elaborate only when the reader asks for it. This applies to chat replies, not only to documents.

## Method
1. Write the message.
2. Remove every word or phrase that carries no meaning.
3. Verify each conclusion has data or a traceable derivation.
4. Flag any remaining assumption explicitly.

## Checklist
- [ ] A yes/no question got only yes or no
- [ ] Every word carries meaning
- [ ] Conclusions have data or an explainable derivation
- [ ] Assumptions stated explicitly (or removed)
- [ ] No filler or hedging qualifiers
- [ ] Tone is polite and direct
